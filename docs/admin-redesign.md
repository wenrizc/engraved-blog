# 管理页编写流程重设计

调研日期：2026-10-09。此次改动覆盖 `local-admin/`，继续使用现有的 Markdown 内容库与 Astro 摄影数据结构。

## 参考资料

直接检索并阅读了以下官方文档：

- [WordPress Gallery block](https://wordpress.org/documentation/article/gallery-block/)：批量添加、拖入图片、每张图片的说明与替换，提供拖动和箭头两种排序方式。
- [Ghost Using the editor](https://ghost.org/help/using-the-editor/)：编辑工具栏，以及在编辑器内调整图片的入口。
- [Ghost Publishing and scheduling](https://ghost.org/help/publishing-content/)：顶部固定预览与保存入口，桌面和手机阅读预览，内容设置与写作分开。
- [Markdown Guide Basic Syntax](https://www.markdownguide.org/basic-syntax/)：标题、引用、链接和代码块的标准写法。

## 问题与对应改动

| 原来的问题                             | 新的行为                                                   |
| -------------------------------------- | ---------------------------------------------------------- |
| 所有字段和上传操作混在一个长表单里     | 左侧内容库，中间写作，右侧内容设置；导入放入独立窗口       |
| 字段标签很小、纸纹干扰阅读             | 控件使用系统字体、稳定浅色配色，标题与阅读预览保留衬线字体 |
| 要先选择照片，再找页面底部的上传按钮   | 批量选择或拖入后立即显示，最终点击保存时统一上传           |
| 图片路径占据主要编辑空间               | 缩略图、说明、封面和排序直接可见；文件信息折叠显示         |
| 中文文件名图片可能无法显示，大图加载慢 | 路径编码，服务端生成并缓存缩略图，原图用于图片编辑         |
| 没有图片排序                           | 拖动手柄、前后箭头和序号输入；图集按顺序保存               |
| 替换或删除容易重做                     | 替换保留说明、位置和封面；图片结构操作支持最近 30 步撤销   |
| 没有图片编辑                           | 查看、左右旋转、比例裁剪、调整取景位置，应用为新的图片文件 |
| 看不到 Markdown 效果                   | 编写、分屏预览、阅读预览，桌面与手机宽度切换               |
| 修改标题就改变已有文件名               | 已有文章和摄影作品保留文件名；面试笔记可调整目录           |
| 保存后跳到第一篇内容                   | 保存后保持当前条目和编辑视图                               |
| 切换或刷新丢失修改                     | 自动本机暂存；切换时提供保存、暂存或继续编辑；刷新后可恢复 |
| 导入覆盖当前编辑状态                   | 导入只更新内容库，不清空正在编写的正文                     |
| 草稿只是“是/否”，与本地保存混淆        | 明确“草稿 · 仅后台可见”与“公开 · 构建后展示”，新建默认草稿 |
| 多个编辑窗口可能覆盖更新               | 文件版本检查，冲突时保留浏览器内的修改并提示               |

## 编辑流程

1. 在内容库选择文章、照片或面试八股，搜索或按状态筛选，也可以新建。
2. 写标题、摘要和正文；日期、标签、状态、目录在内容设置中填写。
3. 摄影作品添加照片，写说明，设置封面并调整顺序。点击照片或“编辑”可以裁剪、旋转。
4. 使用分屏或阅读预览检查当前未保存的内容。
5. 点击顶部“保存 Markdown”或按 Ctrl / Cmd + S。新增和修改的图片先写入资产目录，然后保存正文、说明、封面和顺序。
6. 运行项目构建，按原来的 Git 工作流发布网站。

## 保存和恢复

- 本机暂存使用 IndexedDB，包含文字和待保存的图片 File 对象。浏览器源地址改变、清理站点数据或更换设备后不能共享这些暂存。
- 暂存成功与项目保存成功分别显示。浏览器无法暂存时会提示，并阻止“暂存并继续”丢弃当前修改。
- 图片上传成功但 Markdown 保存失败时，保留已上传路径；再次保存不会重复上传。未被内容引用的资产仍保留，便于恢复。
- 图片裁剪与旋转生成 PNG 副本，原始文件保留。支持原图、1:1、4:3、3:2、2:3、16:9，可调整裁剪区域的水平与垂直位置。
- 已保存 Markdown 的额外元数据会保留。保存使用临时文件与原子重命名，后台保存任务按顺序处理。
- 封面只影响作品列表；图集详情顺序由照片数组决定。原内容中仅有封面的照片会纳入可编辑图集。
- 删除继续使用 `.local-admin-trash`，不会清理图片资产。

## 预览范围

预览即时显示标题、摘要、日期、标签、图集、说明和 Markdown 正文。正文支持常见语法、GFM 表格与任务列表，链接在新窗口打开；内嵌脚本和危险链接会被过滤。公开目录图片和项目摄影资产可加载。

这是工作台的阅读预览，不是完整网站页面：不会还原主站导航、图片灯箱、代码高亮或任意 HTML/MDX 组件。主站最终效果仍以 Astro 构建为准。选择“公开”并保存也不会自动部署。

## 验证

`npm run test:admin` 在独立临时目录中测试，覆盖桌面、平板和手机：路径与元数据保留、保存后选择状态、Markdown 预览、中文缩略图、图片排序/撤销/替换、待保存图片恢复、裁剪旋转、保存失败后重试、文件冲突、导入保留正文。拖动手柄另外在桌面验证。

已有的面试库集成测试继续验证嵌套导入、目录编辑、主站列表/搜索以及草稿隔离。
