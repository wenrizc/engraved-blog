# 前端布局约定

本站公共前端采用正常文档流、Grid 和 Flex 排版。位置稳定指同一视口下，共享导航和栏目起点保持一致，随机诗歌及资源加载不会推动邻近模块。改变视口会触发明确的响应式布局；文章正文和长标题允许自然向下增长。

## 样式职责

- `src/styles/global.css`：仅组织字体和样式入口。
- `src/styles/tokens.css`：颜色、字体、间距、最大宽度、页面边距和诗歌区域高度。
- `src/styles/base.css`：盒模型、基础文字/图片、焦点和减少动画规则。
- `src/styles/layout.css`：共享页面容器与页脚布局。
- `src/styles/components.css`：导航、首页、卡片、栏目标题、正文和灯箱内部规则。

避免在页面内复制容器宽度和水平边距。首页、栏目页、详情页、页头及页脚都使用 `--content` 和 `--page-gutter`。整个盒模型采用 `border-box`，声明的宽度包含内边距和边框。

## 容器与定位

普通内容保留在文档流中，父容器通过 Grid/Flex 分配空间，用 `gap` 和 `padding` 决定间隔。`position: relative` 只为装饰层建立定位参照，并不固定元素的高度，也不会阻止内容撑高。`absolute` 用于图框、分隔线等装饰；正文与标题不能依赖绝对定位，否则长内容容易覆盖后面的模块。

Grid 列使用 `minmax(0, 1fr)`，会收缩的子项使用 `min-width: 0`，文字使用适当的换行规则，防止长英文或链接将列撑宽。代码和宽表格在自己的区域内水平滚动。页面不通过 `overflow-x: hidden` 掩盖溢出。

## 稳定尺寸

- 首页标题顶部由容器内边距确定，使用列宽单位 `cqi` 缩放字号，不再按包含诗歌的整列高度居中。
- 随机诗歌使用 `--poem-height: 18rem` 的独立区域。长诗内部滚动，链接仍可进入完整诗歌。`min-height` 只能规定下限，无法保证内容变化时高度不变，因此不用于该动态区域的尺寸约束。
- 图像由 HTML 固有尺寸和 CSS `aspect-ratio` 预留空间。首页主图优先加载；摄影卡片按图片比例设置画幅，并把极端比例限制在 1:1 到 2.2:1 之间，照片始终完整显示。详情页保持照片原比例，竖图限制展示高度，放大窗口加载单独生成的高清版本。
- 导航以七个固定轨道排版，每项内容在轨道内水平居中，使等宽的中文标签保持等距节奏；激活/悬停下划线贴合中文标签宽度，不随轨道拉伸。标签禁止拆字；640px 及以下分成品牌行和导航行。760px 及以下隐藏英文副标签并将主要双栏切为单栏。档案列表在480px及以下把标题放到第二行。
- 栏目标题共用行高和最小区域高度。详情页的长标题自然换行，不强制固定高度，以保证文字完整可读。
- 根元素预留滚动条宽度，切换长短页面不会改变可用宽度。
- `body` 通过纵向 Flex 和 `main { flex: 1 }` 填满屏幕，不再用假定页头/页脚高度的减法。
- 网络字体采用 `display=optional`。网络慢时使用系统回退字体，避免首屏完成后字体替换引起重排；不同设备仍可能显示不同字形。

## 验证

执行 `npm run test:layout`。首次运行可用 `npx playwright install chromium` 安装浏览器；也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已有 Chromium。配置会自动使用本机 `/usr/bin/google-chrome`（如存在）。

检查覆盖手机、平板、桌面，以及320–1920px之间的关键断点：跨tab坐标、超长诗句、详情页长标题、长链接、宽表格、代码、页脚及图片加载前后的尺寸。测试阻断外部字体，验证字体服务不可用时的排版。断点扫描只运行一次，因此其余两个项目显示跳过。

同时运行 `npm run build`、`npm run smoke`、`npm run lint`。自动几何检查不能替代视觉审核；设计修改时仍应检查字体实际可用时的桌面和手机页面。
